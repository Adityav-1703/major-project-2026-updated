# Ayurvedic Blockchain Frontend

## Run

1. `cd ayurvedic-blockchain-frontend`
2. `npm install`
3. `npm run dev` - opens http://localhost:5173

## Features
- React + Vite + TS
- Tailwind + Shadcn UI
- Framer Motion animations
- React Three Fiber 3D
- Glassmorphism + Neon theme
- Full responsive
